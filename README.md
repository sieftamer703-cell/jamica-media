# Jamica Media

Static bilingual (Arabic/English) marketing agency website with light/dark mode, contact links, and an SVG logo.

## Preview
Open `index.html` in your browser, or use VS Code Live Server.

## Free hosting with GitHub Pages
1. Create a public GitHub repository named `jamica-media`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait for deployment. Visit `https://YOUR_USERNAME.github.io/jamica-media/`.

## Important
- Packages are illustrative, not binding offers.
- Portfolio cards are explicitly labeled as sample concepts.
- Contact form sends the visitor to WhatsApp; it does not save data.
- Edit contact details in `index.html` and `script.js` if they change.
- Google Fonts needs an internet connection; system font fallbacks work offline.
